# Changelog

All notable changes to this project are documented here.
Format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versioning follows [SemVer](https://semver.org/).

## [0.1.0] - 2026-11-25

### Added
- Initial public release
- Serial device discovery for Windows / macOS / Linux
- ISO/IEC 14443-A tag identification (ATQA / SAK decode, UID read, CRC-A)
- ISO/IEC 14443-B ATQB parsing and CRC-B
- ISO/IEC 15693 inventory and UID helpers
- `rfidtoolkit` CLI with `devices` and `identify` subcommands, JSON output
- Hardware compatibility matrix (`data/compatibility.json`)
- Legal notice, security policy and contribution guide
