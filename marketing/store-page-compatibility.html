The RFID/NFC Toolkit is an open-source Python library for reading, identifying and analyzing RFID/NFC tags on hardware you own or are authorized to test. It talks to your reader over USB serial or PC/SC and gives you the protocol layer directly: ATQA/SAK decoding, ATQB parsing, ISO 15693 inventory, CRC-A/CRC-B utilities, and JSON output you can pipe into asset-management pipelines.

Every device on this page is stocked here at Hacker Warehouse and has been matched to the compatibility matrix maintained in the project repository. If you are choosing a reader, the second table maps workflows to hardware.

Install it in one line:

pip install -e git+https://github.com/WilliamChen55/rfid-nfc-toolkit.git#egg=rfid-nfc-toolkit
rfidtoolkit devices
rfidtoolkit identify --port COM5 --json

Scope and responsible use

The toolkit reads, identifies and analyzes. It does not implement key recovery, credential recovery, duplication or access bypass. Use it only on tags, cards and readers that you own or have written authorization to test, and follow the radio and computer-misuse rules of your jurisdiction. Deliberate interference and jamming are prohibited.

Questions about a specific reader, or a firmware combination that is not listed? Send us a message with your model and firmware version — compatibility reports go straight into the matrix.
